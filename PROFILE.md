# AI for Database

AI-powered database platform offering natural-language querying (text-to-SQL), dashboards, reports, and scheduled database workflows with query approval. Exposes a scoped Bearer-auth REST API with a public OpenAPI 3.1 contract, plus agent-native discovery surfaces (llms.txt, llms-full.txt, and a JSON capability manifest). Supports PostgreSQL, MySQL, MongoDB, SQL Server, and Google Sheets.
